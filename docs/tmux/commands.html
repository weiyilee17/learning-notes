Keyboard shortcuts

Leader = Ctrl + b remapped Leader to Ctrl + s in .tmux.conf

  • Leader + c = Create a new window

  • Leader + n = Move to next window

  • Leader + 1 = Move to window 1

  • Leader + % = Split window vertically, into left and right pane

  • Leader + " = Split window horizontally, into top and bottom pane

  • Leader + arrow to navigate between panes

  • Leader + : = Change to command mode

    • rename-window [new window name]
    • rename-session [new session name]

  • Leader + d = Detach tmux session, back to terminal

  • (in terminal) tmux ls = list all tmux sessions

  • (in terminal) tmux attach = attach back to tmux session

  • (in terminal) tmux = create a new tmux session

  • Leader + s = list tmux sessions

  • Leader + w = list tmux sessions and windows

config at ~/.tmux.conf
after adding r rebind in .tmux.conf, Leader + r = reload tmux config file

  • Leader + h, j, k, l = Leader + arrow after rebind in config file

  • Leader + I = Install plugins listed in tmux plugin manager(tpm)

Plugins are in ~/.tmux/plugins

terminal with fzf, not tmux specific​

  • nvim + ctrl + t = opens fzf interface to find file or
    directory to open

  • cd + ** + tab = opens fzf interface to find file or
    directory to open

  • nvim + ** + tab = same

  • ctrl + r = show command history

terminal with lazygit, not tmux specific​

  • 1 ~ 5 = focus on certain block
  • h, l = go to next / prev block
  • ? = show key bindings
  • / + filter text = search through keybindings list

Files​

  • d = discard all changes

  • D = more options

  • space = toggle staged

  • enter + space on certain line = enter file and
    stage specific hunk

  • tab + d on certain line = go to staged hunk and deselect

  • c = commit changes

  • tab = switch focus to commit description

  • P = push to origin

  • p = pull from origin

Local Branches​

  • n = create new branch
  • o = open pr

Rebase​

While checked out on branch, highlight main branch and press
r to rebase

Conflicts​

  • enter = enter conflict file
  • space = select current or incoming
  • e = edit current file

Commits​

  • e = interactive rebase
  • ctrl + j, k = swap order
  • m = rebase options
Cherry pick​
  • c on commit = copy
  • switch to brach and p = paste to brach
Stash Conflicts (git stuff, not related to lazy git)​
  • Solve merge conflict
  • Save
  • Commit
  • git reset HEAD^
  • git stash drop stash@0
