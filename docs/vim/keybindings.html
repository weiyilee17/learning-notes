Key Bindings

These are notes for me to lookup in the future. Some may not be the default​

Some are key bindings related to plugins like telescope​

but the keybindings that have been remapped​

  • Ctrl + h, l = move to left and right pane

  • : + v + s = vertical split

  • Ctrl + w + v = vertical split

  • Ctrl + w + s = horizontal split

  • ~ = toggle space

  • u = undo (like Ctrl + z)

  • Ctrl + r = redo (like Ctrl + Shift + z)

  • Ctrl + - = go to previous file

  • Ctrl + g + d = go to definition

  • Ctrl + g + r = go to reference

  • Ctrl + o = go out to the file you were just in

  • Ctrl + i = go in to the file you just checked

  • Ctrl + n = go in to the next suggestion

  • Ctrl + p = go in to the previous suggestion

  • * = Searches for the word under the cursor

  • n, N = next, prev match

  • gn = operate on this match

  • cgn = change this match

  • Esc + n + . = repeat on next match

when cursor on {

  • % = move cursor to closing counterpart

  • shift + k = show type definition

Ex.

  • c + i + w = change in word
  • y + a + p = yank around paragraph
  • n = go to next match
  • . = replay what is done previously

sed​

  • : + % + s + regex (ex./Post) + / + what wants to be changed to + / + g(/g for global replacement /gc for interactive changing (Y/N) to control )

  • v + i + w = highlight word

  • y = yank the word

  • Leader + f + g = telescope search word

  • Ctrl + q = put the search result in quick fix

  • : + cdo = execute arbitrary command in every single
    file in the quick fix list

  • s/previous/next/gc = substitute previous to next globally and needs confirm

So the above combo replaces all string previous to string next, and asks user confirmation

Registers​

  • : + reg = list registers

  • " + # of reg + p = past content from # of register

  • " + # of reg + y = yank content to # of register

  • * reg = system clipboard(* for mac, + for linux)

  • % reg = file path

  • :let + @+=@%= copy file path to system clipboard

Macros​

  • q + # of reg = start a macro at # of register(ex. h register)

  • record actions (hopefully starts at new line so could be repeated)

  • q to finish recording

  • @ + # of reg = replay macro recorded at # of
    reg (ex. for h register, @h)

  • 5 + @ + h = replay the macro @h register 5 times

  • edit macros

  • : + new = new buffer

  • : + put + # of reg = view content
    of # register (ex. register a)

  • edit register

  • " + # of reg + yy = yank updated
    register content

  • quit buffer and replay updated macro

P = Toggle preview mode

- = open parent directory

commentary​

gcc = comment line 3 + gcc = comment 3 lines Visual Mode + gc = comment selected lines gcap = comment around paragraph
